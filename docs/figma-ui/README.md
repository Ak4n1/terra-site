# Terra Figma UI Assets

## Importar en Figma

1. Abrir el archivo Figma donde quieras trabajar.
2. Usar `File > Place image/video`.
3. Seleccionar `terra-account-dashboard.fig-ready.svg`.
4. Hacer click en el canvas para colocarlo.
5. Si Figma lo importa agrupado, usar `Ungroup` para editar capas internas.

## Archivo

- `terra-account-dashboard.fig-ready.svg`: concepto de dashboard de cuenta Terra con frame desktop y mobile.

El SVG usa capas nombradas (`Desktop_Frame`, `Mobile_Frame`, `Sidebar`, `Quick_Actions`, etc.) para que sea mas facil editarlo despues de importarlo.
